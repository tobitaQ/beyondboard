# E8：画像の課題で、ボードの中とクラウドを比べる（計測の前に決めた手順、2026-10-02）

**問い**：ボードだけではできない、またはやりにくい画像の処理が、BeyondBoard を使うとどこまで 1 行で届くか。その代わりに何を払うか（時間・電力・データの行き先）。

この文書は、どちらの検出器もまだ動かしていない時点で書いた。以下の条件は、結果を見てから変えない。変えた場合は、変えた理由と日付をこの文書の末尾に書く。

## 1. 画像（`select_images.py`）

- **顔のある画像 40 枚**：WIDER FACE の検証用（公式の配布、CC BY-NC-ND 4.0）。顔の数 1〜5 ごとに 8 枚ずつ、乱数の種 1 で選ぶ。
  - 640×480（カメラの画像の大きさ）に収まるように縮め、黒で余白を足す。
  - 有効な顔（invalid が 0）がすべて、短い辺 32 ピクセル以上のものだけを選ぶ（小さすぎて、検出できなくても仕方がない顔を含めない）。
  - 正解の顔の位置は、WIDER FACE の注釈を同じ倍率で変換したもの。
- **顔のない画像 10 枚**：COCO val2017 のうち、「person」の注釈がないものから、同じ乱数で選ぶ。同じように 640×480 にする。
- **JPEG の大きさ**：カメラの写真（15〜23 KB）に合わせて、品質 25 で保存する（11〜34 KB、中央値 18.5 KB）。esp32-camera の「品質 12」とは尺度が違うので、ファイルの大きさで合わせた。
- 画像そのものは Git に入れない（ライセンスと、人が写っているため）。`selection.csv` で、どの画像を使ったかを残す。

## 2. 比べるもの

| 腕 | 中身 | 環境 |
|---|---|---|
| ボードの中 | esp-dl の 2 段階の顔検出（HumanFaceDetectMSR01 + MNP01）。しきい値は arduino-esp32 2.0.14 の CameraWebServer の例題のまま（0.1, 0.5, 10, 0.2 / 0.5, 0.3, 5） | arduino-esp32 **2.0.14**（3.x には esp-dl が入っていない）、ESP32-S3（PSRAM が必要） |
| BeyondBoard | `aws.save` で保存し、`aws.run("countFaces", name)`（Amazon Rekognition DetectFaces、既定の設定）。位置は `faceBoxes`（同じ API で、位置を返すだけ） | arduino-esp32 3.3.5、ESP32-S3、Wi-Fi 2.4 GHz、AWS 東京 |

- 両方とも同じ JPEG のバイト列をフラッシュに埋め込んで使う（`make_header.py` → `images.h`）。カメラは使わない。
- どちらも、しきい値を調整しない。

## 3. 測るもの

- **顔の数**：平均絶対誤差（MAE）、平均の符号付き誤差（多すぎ・少なすぎの傾向）、正確に一致した割合。顔のない 10 枚で 1 つ以上検出した割合。
- **位置**：IoU 0.5 以上で正解と対応づけたときの適合率・再現率・F1（貪欲法で、IoU の大きい順に 1 対 1 で対応づける）。
- **差の検定**：画像ごとの絶対誤差に Wilcoxon の符号順位検定、一致したかどうかに McNemar 検定。ブートストラップ（1 万回、種 1）で 95% 信頼区間。
- **時間**：ボードの中は JPEG の展開と検出の時間。BeyondBoard は `save` と `run` の時間（ボードで測る）。3 回通して（リセットで繰り返す）、中央値と p95。
- **ボードの資源**：フラッシュと静的 RAM（コンパイルの結果）。画像を除いた大きさも出すため、画像 1 枚だけで同じスケッチをビルドする。処理中の空きメモリの最小値（ヒープと PSRAM）。
- **料金**：1,000 枚あたりの目安（Rekognition の料金表、2026-10 時点）。
- **写真の説明**（`ask`、最初の 10 枚）：かかった時間と答え。ボードの中ではできない。

## 4. 限界として最初から書いておくこと

- WIDER FACE は Web の写真で、ドアのカメラの画像とは違う。
- ボードの中の検出器は、Arduino から使える範囲のもの（2019 年ごろの esp-dl のモデル）。ESP-IDF を使えば新しいモデルもあるが、Arduino IDE からは外れる。
- 画像は 50 枚で、小さい標本である。
